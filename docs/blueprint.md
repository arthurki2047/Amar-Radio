# **App Name**: Amar Radio

## Core Features:

- Keypad Navigation: Enable navigation through radio stations using keypad buttons on mobile devices.
- Radio Web Streaming: Stream radio content from web sources, specifically https://liveradios.in/language/bangla.
- Station Search: Allow users to search for radio stations by name or genre using keypad input.
- Preset Stations: Allow users to save and access their favorite radio stations via keypad shortcuts.

## Style Guidelines:

- Primary color: Vibrant orange (#FF9500) to evoke energy and enthusiasm.
- Background color: Light beige (#FAF9F6) for a soft and unobtrusive backdrop.
- Accent color: Teal (#008080) to complement the orange and add a modern touch.
- Body and headline font: 'PT Sans', a humanist sans-serif.
- Use simple, clean icons for radio functions such as play, pause, and search.
- Keypad interface optimized for one-handed use on mobile devices.
- Subtle transitions when switching between radio stations.
